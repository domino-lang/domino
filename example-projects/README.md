# Example projects
This directory contains representative examples of Domino features 
and proof formalizations.

## 4WHS
The IEEE 802.11i four-way handshake is an authenticated key exchange protocol
used in Wi-Fi networks. The security model captures static corruption of parties.

## Yao
This is a formalization of [Brzuska and Oechsner's](https://eprint.iacr.org/2021/1453) 
state-separating proof of Yao's garbling scheme for layered circuits. We formalize 
Layer Security and a hybrid argument for circuit security.

## KEM-DEM
This directory contains 5 formalizations of the KEM-DEM paradigm for 
constructing hybrid public key encryption schemes. One proof is written in 
state-separating proofs (SSP) style, and 4 proofs are written using the 
blended approach.

## hello-world-*
These are basic examples demonstrating key concepts and features of Domino such as 
writing invariants and randomness mappings, hybrid arguments and oracle 
renaming in the compositions.

## simple-KEM-example
This is a basic example demonstrating CPA security of a simple KEM-based protocol.
